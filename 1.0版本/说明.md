## 这一版做到了什么

单课程闭环可用：上传课件 → 解析分块 → 生成带出处的结构化笔记 → 三种格式导出 → 基于材料问答。

- 多格式解析：9 类解析器 / 16 种扩展名
- 证据绑定：每条知识点必须能回查到原文，查不到即丢弃
- 问答三态：可答 / 依据不足 / 材料未涉及，不编造
- 导出：Word / Markdown / LaTeX
