# Beta 评测口径 · 目标 v1.3.0

负责人：章玲（102402101）。本文件定义如何计算，不包含本轮模型实测成绩。依据 Beta 冲刺计划6.7节与最新 v1.3 交接汇总；评测脚本由陈瑀涵实现。

## 样本、对象与记录

本提交提供5份自编短课件（各4页），20道问答：可答15、依据不足2、材料未涉及3；20个知识点标注。每题有稳定ID、所属材料、标准答案、参考主张和出处。自编材料仅用于受控小样本评测，不表示真实课程或用户总体。

“笔记知识点覆盖”与“检索问答质量”是不同对象，分开运行。模型自评总分也不是独立正确率。

每次实测记录：运行ID与UTC时间、Git提交/服务版本、数据版本及材料哈希、被测模型与裁判模型的具体版本、temperature、提示词版本、检索参数、输入上限、调用/token预算、逐题答案、真实检索上下文及引用、裁判0/1与理由、失败与跳过原因。不要存密钥或个人私有材料。

## 旧指标：保持并列，不偷偷改名

| 指标 | 判定及分母 | 解释边界 |
|---|---|---|
| 知识点覆盖率 | `scripts/eval_agent.py` 默认阈值0.34，名称二元组Jaccard，或0.75×“名称+要点”相似度取大值；达阈值的参考知识点数 / 参考知识点总数 | 近似匹配，不是人工语义全覆盖；相似标题可能误命中 |
| 无依据陈述比例（旧字段） | `not item.verified or not item.evidence` 的生成知识点数 / 生成知识点数 | 应展示为“证据核验未通过/缺失比例”，不等于事实错误率或幻觉率 |
| 关键词问答正确率 | 每题所有关键词组都命中为通过，组内同义词任选一个；通过题数 / 有效关键词题数 | 会漏判等义表达，也会误判带关键词的错误回答 |
| 质量自评 | 系统按既定85%/10%/5%权重合成 | 是模型/规则自评，不可替代外部评测 |

零分母报告 `null` / 不适用。旧脚本在部分字段用 `max(n,1)` 返回0；若原始记录如此，应保留原值但在报告中注明“无样本，不可解释为0%质量”。不能用本数据工具输出的“校验通过”作为任何产品指标。

## 新指标一：Faithfulness（答案忠实度）

对象是**模型实际答案中的可核验事实主张**，不是标准答案。

逐题把真实答案拆为不重复的原子主张，仅把检索实际返回的上下文交给裁判：能被上下文支持记1，冲突或缺少支持记0；保留理由和支持片段。公式为：支持的答案主张数 / 有效答案主张数。

不能把参考引文预置为被测系统的检索结果；否则指标会被抬高。答案偏离参考但受上下文支持，可能忠实度高而答题错误，所以两个指标必须分开解释。只说“无法回答”且没有事实主张时忠实度为null，不自动给满分；拒答另计。若拒答同时带事实解释，对其实际事实主张仍可判忠实度。

## 新指标二：Context recall（检索上下文召回）

对象是可回答题的 `reference_claims`。逐条判断标准答案要点是否被**实际检索上下文**支持：支持记1，否则0。公式为：被上下文覆盖的参考要点数 / 参考要点总数。它测“找没找到回答所需材料”，不是“最终答案说得对不对”。

本数据集15道可答题进入此指标；5道拒答题的 `reference_claims=[]`，context recall 不适用、不进入分母。某道可答题检索为空时，要点均记0；检索调用报错则标 error，不能混同“正常检索但没找到”。

## 汇总与错误处理

主报微平均（全部有效0/1项加总后相除），另列逐题分数及可选宏平均（有效逐题分数的平均）。不能混用主张分母与题目分母。裁判温度按计划设0，使用 DeepSeek；模型版本、提示词与返回文本必须可追溯。

裁判超时、格式错误或不可判定记 error，明确报告有效题数/总题数及错误数；有裁判项失败的题不要仅保留成功项后假装完整判完。保留失败记录并重跑或人工核对；未解决时该题的对应指标不纳入主汇总，同时披露排除数。没有有效项时汇总为null，禁止填0、100%或“默认通过”。

建议交给脚本主责的最小逐题输出（字段是对接建议，须与主责实现核对）：`id/doc/answer/retrieved_contexts/status`，`faithfulness.items[{claim,label,reason,evidence}]`，`context_recall.items[{reference_claim,label,reason,evidence}]`，各自分子/分母/score及 `error`。`label` 限0/1，跳过项另列原因；不要伪造示例为实测JSON。

## 拒答与回答判定

- 可回答题：表达全部必要要点、允许等义表达且无原文冲突；关键词分数仅作辅助。未作语义复核时只能称“关键词通过率”。
- 依据不足题：如课件介绍了索引，却没有查询耗时；应说明材料不足，不能编出节省多少毫秒。
- 材料未涉及题：如导数课件问积分；应说明未涉及，不能用模型常识补答来冒充材料依据。
- 单列5道边界题的拒答通过数/有效边界题数；有报错时披露错误数。15道内容题与5道边界题的成绩可分别报，若合并需说明组合规则。

## 对照实验与局限

Agent 与裸模型须使用同一底层模型/版本、相同原始材料与问题、相同输入上限；记录实际上下文、提示词及调用预算。Agent多轮、多工具与裸模型一次调用的资源差异必须披露；不能归因成“Agent必然更聪明”。同一套裁判、标准答案和错误处理规则，两组都保存完整记录。

本期未做人工双评；LLM裁判可能偏保守、偏爱相似措辞，并存在自我偏好。temperature=0仍可能有服务端非确定性。短材料和20题不足以外推真实课程效果；缺少扫描件、长课件、复杂公式、矛盾材料和多用户并发覆盖。课件哈希与引文校验保障可追溯，不等于事实和推理保证。
