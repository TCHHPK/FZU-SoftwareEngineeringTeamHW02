| 项 | 内容 |
| --- | --- |
| 版本 | v1.3.0（Beta 冲刺） |
| 定稿 | 2026-11-23，徐张睿主笔；文字由章玲收口 |
| 适用范围 | K1 复习包、K2 考前冲刺计划、K3 出处抽屉、K4 今日待复习、K5 执行轨迹 |
| 冻结规则 | 本文件冻结后，端点路径、字段名、错误码不再变更；只允许新增可选字段 |

契约先行，是因为上一轮三方合并时：一边的接口要 `error_message` 列、另一边的建表语句里没有，
页面显示假数据、路由文件放错目录——三个人都说"做完了"，合起来跑不起来。
所以本轮先把表与端点写死，各方按此并行。

## 一、约定（所有新端点都适用）

**响应包络**（沿用现有实现，不新增格式）：

```json
{ "code": 0, "message": "ok", "data": { ... } }
```

**鉴权**：除 `/api/health`、`/api/meta`、`/api/auth/*` 外，全部要求
`Authorization: Bearer <token>`，未登录返回 401。

**错误码约定**：

| 状态码 | 含义 | 说明 |
| --- | --- | --- |
| 400 | 参数不合法 | 例如考试日期早于今天、每日时长 ≤ 0 |
| 401 | 未登录 | 不带或带错 token |
| 404 | 资源不存在或无权访问 | 越权一律 404，不用 403，避免被枚举 |
| 409 | 状态冲突 | 例如试卷还在出题中、复习包正在生成 |
| 500 | 服务端异常 | 不允许把内部堆栈返回给前端 |

**分页**：列表端点统一 `?limit=&offset=`，`limit` 默认 20、上限 100。

## 二、新增表与字段（迁移 003）

### 2.1 `wrong_questions` 新增六个调度字段（K4）

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `state` | TEXT | `'new'` | `new` / `learning` / `review` / `relearning` |
| `stability` | REAL | `0` | FSRS 记忆稳定性（天） |
| `difficulty` | REAL | `0` | FSRS 难度（0–10） |
| `due_at` | TEXT | `NULL` | 下次到期时间，ISO8601 UTC；为空表示尚未排期 |
| `review_count` | INTEGER | `0` | 复习次数 |
| `last_review_at` | TEXT | `NULL` | 最近一次复习时间 |

**索引**：`idx_wq_due (user_id, due_at)`、`idx_wq_state (user_id, state)`。

**为什么用 `conn._BUSINESS_MIGRATIONS` 加列**：SQLite 的 `ALTER TABLE ADD COLUMN`
不支持 `IF NOT EXISTS`，重复执行会报 `duplicate column`。迁移必须可反复执行
（线上每次启动都会跑），所以这六列走"先查 `PRAGMA table_info` 再 ALTER"的路径，
`migrations/003_review_plan.sql` 只放能幂等建表与建索引的部分。
已用 `scripts/verify_migration_003.py` 在真实老库副本上验证：升级两次均成功、老数据不变。

## 三、六个新端点

> 顺序即依赖顺序：沈文驰的接口先落地，前端与 Agent 侧随后接入。
> `schemas/api_io.py` 的模型由沈文驰统一写入（C5 裁决：模型先行，路由后接）。

### 3.1 `POST /api/sessions/{session_id}/review-pack` —— 生成复习包（K1）

- **主责**：沈文驰 ｜ 截止 11.28 22:00
- **请求**：无 body（按 session 聚合），可选 `{"include_mindmap": true}`
- **响应 `data`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `pack_id` | int | 复习包 id（新建一行的主键） |
| `chapters` | array | 五章元信息，见下 |
| `generated_at` | string | 生成时间 |

`chapters` 每项：`{"key": "notes|points|mindmap|quiz|wrong", "title": "...", "item_count": 0, "empty": false}`

- **空章规则（C4 裁决）**：某章无数据时 `empty=true`，导出时写"本次未生成此项"，不报错；
  **不允许**在导出时临时生成导图。
- **错误**：404 任务不存在或不属于本人；409 同一 session 正在生成中。

### 3.2 `GET /api/review-packs/{pack_id}/export?fmt=docx` —— 导出复习包（K1）

- **主责**：沈文驰 ｜ 截止 11.28 22:00
- **参数**：`fmt` 目前只支持 `docx`（`md` 为可选后续）
- **响应**：二进制文件流，`Content-Type: application/vnd.openxmlformats-officedocument.wordprocessingml.document`，
  `Content-Disposition` 带文件名（课程名 + 复习包 + 版本号）
- **单章渲染失败**：只降级该章，整体仍可导出（在文档里标注该章生成失败）
- **错误**：404 复习包不存在；400 `fmt` 不支持

### 3.3 `POST /api/sessions/{session_id}/review-plan` —— 考前冲刺计划（K2）

- **主责**：沈文驰 ｜ 截止 11.29 22:00
- **请求**：

```json
{ "exam_date": "2026-12-20", "daily_minutes": 60 }
```

- **响应 `data`**：

```json
{
  "days": [
    { "date": "2026-11-24", "total_minutes": 55,
      "items": [ { "knowledge_name": "等价类划分", "minutes": 15, "reason": "错 3 次，且 2 天内到期" } ] }
  ],
  "exam_date": "2026-12-20",
  "weights": { "weakness": 0.5, "importance": 0.3, "urgency": 0.2 }
}
```

- **算法约束**：每天不超过 5 项、总时长不超过 `daily_minutes`；同一知识点 48 小时内不重复排；
  最后两天只排高频错题与高重要度知识点；每条必须有 `reason`。
- **错误**：400 `exam_date` 早于今天或格式错误、`daily_minutes ≤ 0`；404 任务不存在。

### 3.4 `GET /api/wrong-questions/due?limit=20` —— 今日待复习队列（K4）

- **主责**：沈文驰（后端）｜ 截止 11.30 22:00
- **响应 `data`**：`{"items": [ ... ], "total": 0}`，每项在现有 `WrongQuestionOut` 基础上增加：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `state` | string | 见 2.1 |
| `due_at` | string \| null | 到期时间 |
| `review_count` | int | 复习次数 |
| `is_due` | bool | `due_at <= now` 或 `due_at` 为空 |

- **排序**：`due_at` 升序（空值优先），只返回已到期项，最多 `limit` 条。
- **必须注意路由顺序（已实测踩坑）**：现有 `GET /api/wrong-questions/{wrong_id}` 会把
  `due` 当成 `wrong_id` 解析——未登录返回 401，登录后直接 **422**（"Input should be a
  valid integer"）。所以 `GET /api/wrong-questions/due` 必须声明在 `/{wrong_id}` **之前**；
  `scripts/check_contract.py` 已加自动检测，注册顺序错了会报「被遮蔽」。
- **兼容**：`GET /api/wrong-questions` 的现有字段与结构**不变**，只在响应里新增上述字段。

### 3.5 `GET /api/chunks/{chunk_key}` —— 出处原文（K3）

- **主责**：沈文驰 ｜ 截止 11.28 22:00
- **路径**：`chunk_key` 形如 `d1-p1-c1`（doc 序号-页-块序号）
- **鉴权（C3 裁决，必须照做）**：
  1. 按 `chunk_key` 取 `chunks` 行；
  2. 用其 `doc_id` 反查 `documents`；
  3. 复用 `user_can_access_doc()` 校验 `user_id`（含公共资料判定）；
  4. 不通过返回 **404**（不是 403）。
  **禁止**只按 `chunk_key` 直出内容，否则可枚举他人材料。
- **响应 `data`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `chunk_key` | string | 原样返回 |
| `text` | string | 本块原文 |
| `page_num` | int \| null | 页码 |
| `before` | string | 前一块原文（上下文，可为空串） |
| `after` | string | 后一块原文（可为空串） |
| `source_file` | string | 来源文件名 |

### 3.6 `GET /api/sessions/{session_id}/trace` —— 执行轨迹（K5）

- **主责**：陈瑀涵（后端）｜ 截止 11.29 22:00
- **响应 `data`**：`{"items": [ {"seq": 0, "stage": "解析", "status": "ok", "message": "...", "detail": {...}, "started_at": "...", "ended_at": "..."} ]}`
- **渲染约定（C6 裁决）**：前端按返回的事件序列渲染，**不硬编码阶段数量与名称**；
  对外话术统一"分阶段流水线"，答辩稿不写死"六段"。
- **旁路性**：轨迹写入失败不影响整理主流程；失败阶段 `status='failed'` 但会话状态不变。

| 接口 | 改动 | 说明 |

| `GET /api/self-tests/{id}` | 新增 `target_count`、`actual_count`、`shortfall` | A32 修复：题数不足时不再静默改写题量 |
