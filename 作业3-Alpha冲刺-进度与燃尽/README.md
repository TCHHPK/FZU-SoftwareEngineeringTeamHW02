## 二、统计口径

1. **权重**：把冲刺范围拆成 12 个工作包（W01–W12），按《天生一队-冲刺计划-v2》第 5 节的分工工作量
   占比折算，合计 **100 点（100%）**。
2. **只认验收**：某个工作包验收通过，才把它全部权重计入当日累计完成度；未通过不计，不做
   "完成一半算一半"的估算。
3. **计划值**：按冲刺计划第 4 节里程碑表逐日线性插值。
4. **实际值**：取可核查的客观痕迹——仓库提交记录、CHANGELOG 版本节点（1.0.0 于 11-16、
   1.2.0 于 11-20）、《三方代码合并说明》（11-20 合并）、每日站会记录与发布包打包时间。
5. **时区**：统一按**北京时间（UTC+8）**。GitHub API 返回 UTC，例如 PR #2 记为
   `2026-11-18T18:18Z`，实际为 **11-19 02:18**，故错题本/迁移的完成日记为 11.19。

## 三、复现

```bash
pip install -r requirements.txt
python scripts/make_figs.py     # 需 matplotlib
python scripts/build_xlsx.py    # 需 XlsxWriter
```

脚本里的路径全部相对本目录（`Path(__file__).parents[1]`），换机器、换盘符都不用改代码。
