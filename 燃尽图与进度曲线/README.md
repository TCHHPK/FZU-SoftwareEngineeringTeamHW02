## 二、统计口径

1. **权重**：把冲刺范围拆成 12 个工作包（W01–W12），按《天生一队-冲刺计划-v2》第 5 节的分工
   工作量占比折算，合计 **100 点（100%）**。
2. **只认验收**：工作包验收通过，才把它全部权重计入当日累计完成度；未通过不计，不做
   "完成一半算一半"的估算。
3. **计划值**：按冲刺计划第 4 节里程碑表逐日线性插值。
4. **实际值**：取可核查的客观痕迹——仓库提交记录（`data/commits.csv`）、CHANGELOG 版本节点
   （1.0.0 于 11-16、1.2.0 于 11-20）、《三方代码合并说明》（11-20 合并）、站会记录。
5. **时区**：统一按**北京时间（UTC+8）**。GitHub 记的是 UTC，例如 PR #2 为
   `2026-11-18T18:18Z`，换算后是 **11-19 02:18**，故错题本/迁移的完成日记为 11.19。

## 三、复现

```bash
pip install -r requirements.txt

python scripts/make_figs.py                     # 生成三张图
python scripts/build_xlsx.py                    # 生成数据底表（本地文件，不提交）
python scripts/fetch_repo_evidence.py --git <本地仓库路径>   # 重新拉提交证据
python scripts/verify_release.py <发布包源码目录>            # 复核用例数与编译
```

`fetch_repo_evidence.py` 也支持直接走 GitHub API（`set HTTPS_PROXY=...` 后不带 `--git`），
方便换机器时取数。
