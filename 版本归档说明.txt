把三个版本目录上传到 GitHub
==================================================
仓库：https://github.com/TCHHPK/FZU-SoftwareEngineeringTeamHW02
待上传目录：桌面 \ GitHub上传-三个版本

为什么由你来点：这台电脑连不上 github.com（超时 / 连接重置），
克隆两次都失败，推送更不可能成功。网页上传走的是浏览器通道，
反而更稳，而且 9 MB 没超过网页单文件 25 MB 的限制。

--------------------------------------------------
方式 A：网页上传（推荐，2 分钟）
--------------------------------------------------
1. 浏览器打开仓库首页，确认当前在 main 分支

2. 点右上「Add file」→「Upload files」

3. 把桌面上的这三个文件夹**整个拖进**上传区域：
       1.0版本
       1.1版本
       1.2版本
   浏览器会保留目录结构（每个文件夹里是 1 个 zip + 1 个 说明.md）

4. 等进度条走完（1.1 版本那个 9 MB，稍慢），
   底部 Commit changes 填：
       docs(版本): 归档 1.0 / 1.1 / 1.2 三个版本交付物
   选「Commit directly to the main branch」→ Commit

5. 刷新仓库首页，确认出现三个文件夹

注意：如果拖拽不保留目录，就分三次上传：
   先上传 1.0版本/ 里的两个文件，提交后在仓库里点「Add file → Create new file」，
   文件名填  1.0版本/占位.txt  保存，仓库就会建出这个目录；
   再进该目录用 Upload files 传 zip 和 说明.md。其余同理。

--------------------------------------------------
方式 B：命令行（如果你有代理/能连 github）
--------------------------------------------------
在 PowerShell 里执行（会弹浏览器让你登录 GitHub）：

    cd "$HOME"
    git clone https://github.com/TCHHPK/FZU-SoftwareEngineeringTeamHW02.git repo
    cd repo
    Copy-Item -Recurse -Force "$HOME\Desktop\GitHub上传-三个版本\1.0版本" .
    Copy-Item -Recurse -Force "$HOME\Desktop\GitHub上传-三个版本\1.1版本" .
    Copy-Item -Recurse -Force "$HOME\Desktop\GitHub上传-三个版本\1.2版本" .
    git add "1.0版本" "1.1版本" "1.2版本"
    git commit -m "docs(版本): 归档 1.0 / 1.1 / 1.2 三个版本交付物"
    git push origin main

如果 clone 又失败，先换网络（手机热点）再试；这台机器直连不通。

--------------------------------------------------

等你的分支合进 main 之后，把 1.2版本/说明.md 里的表格更新一下，
标注「已合入 main（commit 号）」；否则评审会以为代码没进仓库。
